# Chili

1. Sweat onions in saucepan.

2. Add a pound of ground beef or turkey, and brown the meat.

3. Add a can of diced tomatoes, chili powder, and any other spices.

   a. If using dried chilies, toast the chilies in a pan, then blend them with some water into a sauce. Add that to the chili.

4. Let simmer for about a half an hour.
